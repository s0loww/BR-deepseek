# Образцы сценариев Vanessa

Обобщены с боевых наборов двух продуктивных 1С-проектов (UI-BDD-стиль +
инфраструктурные конвенции). **В прогон по умолчанию не попадают** —
`featuresDir` контура смотрит на `../features/`.

Как пользоваться: скопировать подходящий образец в `../features/`,
заменить имена объектов, окон и элементов на реальные для проекта
(префикс `xx_` — на префикс проекта из `.dev.env`), прогнать командой
`test`. Правила написания — `DEPLOYMENT.md` §4.1.

| Файл | Класс сценария |
| --- | --- |
| `01-form-smoke.feature` | смоук формы: открывается без ошибок |
| `02-arm-ui.feature` | многосценарная фича АРМ: вкладки, таблица, команда с проверкой лога, отказ с причиной, комментарии-регрессии |
| `03-doc-create-commands.feature` | команды создания документов с проверкой предзаполнения |

Все образцы read-only: данные стенда не меняют.
